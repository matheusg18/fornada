# AGENTS.md: learning notes

This folder holds the maintainer's learning notes: highlights of what they learned in each phase of the project. They are raw material for blog posts, one post per phase.

- **Write here only when the maintainer asks.** These are their notes, not a changelog.
- **One file per phase:** `NN-<slug>.md`, numbered like the roadmap (`00-setup.md` is the setup before phase 1). When you add a file, add a line for it to `README.md`.
- **Highlights only.** Short bullets, one line each where possible. Say what was learned, not how it was done. Add detail only when the bullet makes no sense without it.
- **Reusable lessons.** Prefer lessons that apply to other projects. Leave out details that only matter to this repo.
- **Format:** an `#` title, the bullets, and an optional `Links` list (PRs, docs). Nothing else.
- **Language:** English, like the rest of the repo.
